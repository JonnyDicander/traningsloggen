## Så byggde jag appen 

1. **Skapade en mall för en övning (`WorkoutItem.kt`)** – Varje övning fick ett unikt id, namn, 
kategori och en markering för om den är klar.


2. **Byggde logiken och minnet (`WorkoutViewModel.kt`)** – Här sparas listan med övningar 
och kod som gör att man kan lägga till, ändra, bocka av och ta bort övningar.


3. **Byggde själva skärmen (`MainActivity.kt`)** – Gjorde knappar, textfält, en räknare för klara
övningar och en lista som visas på skärmen.


4. **La till filter på kategorier** – Gjorde så att man kan klicka på t.ex. *Bröst* eller *Alla* 
för att bara se övningar i just den kategorin.
